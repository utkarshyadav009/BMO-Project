# Report assets — inputs used

This folder was generated by `scripts/generate_report_figures.py`.

## Required / optional inputs

| Asset | Argument | Notes |
| --- | --- | --- |
| **Table 1 + Fig 4** | `--metadata` | CSV/TSV; columns `filename`, `transcript` (headers optional). Pipe in filename splits `file.wav|text`. |
| **Fig 4 durations** | `--audio-root` + `soundfile` | If no `duration_sec` column, durations come from WAV length. |
| **Fig 3** | `--septq-ckpt` | PyTorch `.pt` with `tier_masks_uint2` (or under `septq_meta`). Needs `torch`. |
| **Fig 5** | `--zs-json` **or** `--cascade-csv` | JSON from `verify_septq_zs_drift.py --save-json` (`layer_summary.per_layer[].cos_median`). CSV columns: `layer,cosine`. |
| **Fig 1** | `--bf16-gb`, `--gguf-gb`, `--ceiling-gb` | Horizontal bar chart constants. |
| **Fig 6** | `--rss-gb-*` | Schematic stacked components (GB); tune to your profiling notes. |

## Command (example on server)

```bash
cd ~/work/BMO-Project/personaplex_repo
python scripts/generate_report_figures.py \
  --out-dir report_figures \
  --metadata ../bmo_clips_raw/BMO_SpeechDataset/metadata.csv \
  --audio-root ../bmo_clips_raw/BMO_SpeechDataset \
  --septq-ckpt bmo_temporal_half_cushion_max.pt \
  --zs-json zs_half_cushion_max.json
```
