================================================================================
  BMO Voice Engine - Inference Output Samples (CMP511 Report Submission)
================================================================================

Captured: 2026-05-13
Prompt:   Pre-recorded user-side WAV asking "Hey BMO, tell me a joke."
Mode:     Offline inference (moshi.offline / bmo_inference.py stream).
          Live full-duplex inference is not yet validated on the Jetson.

Each .wav below is the agent-side response generated by a specific checkpoint
or compression configuration. They are numbered 01-09 to mirror the
failure-and-recovery narrative in the CMP511 report (baseline -> failed
attempts -> broken pipeline -> failed compression -> final deployment).

--------------------------------------------------------------------------------
  HIGHLIGHTED SAMPLES  (top-level of this folder)
--------------------------------------------------------------------------------

[BASELINES]

  01_v5_step001500.wav
    PersonaPlex 7B + LoRA on the BMO dataset. The "gold-standard" baseline
    referenced throughout the report. Coherent speech, correct timbre.

  02_qat_best.wav
    Best output produced during the 500-step QAT recovery sweep (v12 family,
    pre-GGUF export). Used to validate that SEPTQ + QAT could match the
    baseline acoustically before any C++/GGUF path was involved.


[FAILED EARLY EXPERIMENTS]

  03_bmo_ckpt002500.wav
    Overfitted run on a dataset that still carried non-verbal CLAP tags.
    The tags leaked into the temporal transformer's prompt distribution,
    producing tag-shaped gibberish instead of words.

  04_v6_ckpt001000_joke.wav
    Early personaplex-side experiment whose exact configuration is lost.
    Included for completeness; output is degraded but not catastrophic.


[BROKEN INFERENCE-PIPELINE OUTPUTS]
  (these were produced before the bmo_inference.py rewrite for LMGen /
   moshi.offline parity - they document the "Inference Scaffold Bug"
   described in the Methodology section of the report)

  05_v5_ckpt001500_silence.wav
    PersonaPlex finetune evaluated through the old hand-rolled inference
    scaffold. KV cache was ungrounded; output collapses to silence/noise.

  06_v7A_ckpt001500_silence.wav
    Same symptom on a later finetune. Confirmed the root cause was the
    Python driver, not the checkpoint - fixed once the streaming path was
    rewritten to use LMGen.step_system_prompts.


[FAILED COMPRESSION ATTEMPTS]

  07_v5_step1500_INT4_2.5.wav
    Naive global INT4 quantization of the v5 baseline. The 40-66x acoustic
    activation outliers destroyed the vocabulary geometry; the model no
    longer produces recognizable English. See report Table "Comparison
    Results", row "Global INT4 + LQEC".

  08_2816.wav
    Output of the SliceGPT structural pruning experiment (d = 2816 retained
    dimensions, ~99% variance). The 4421x gain explosion in the Least-Squares
    bridge calibration saturates the logit path - result is uniform noise.


[FINAL DEPLOYMENT]

  09_v12gguf-final.wav
    The final v12 SEPTQ + QAT model exported to GGUF (7.69 GB) and executed
    by the C++/CUDA runtime on the Jetson Orin Nano 8 GB. The Jetson runs
    it via Linux swap + zram-backed compressed swap to absorb the residency
    overshoot relative to the nominal 5.5 GB usable ceiling. Generating
    ~18 s of audio took noticeably longer than real time, but the output
    is intelligible and on-character - this is the empirical proof that
    the full pipeline (SEPTQ -> QAT -> GGUF -> C++/CUDA -> Jetson) is
    end-to-end functional.
